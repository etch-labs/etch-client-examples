# Contributing

The examples are maintained in ETCH's own repository and copied here from it. Each copy replaces
what is here, so a pull request can't be merged into this repository as it stands. Issues are the
way to reach us, and we make the changes upstream.

## Report a problem

Open an issue. Say which example and which language you ran, the command you used, what you
expected, and what happened, with the full error message if there is one. Leave your API key and
package token out of anything you paste.

If the problem is a security vulnerability, don't open an issue. Follow [SECURITY.md](SECURITY.md)
instead.

## Suggest a change

Open an issue that describes the change and why it helps. You can also open a pull request to show
the change. If we take it, we make it in our repository, and it reaches this one with the next copy.

## Before you run the examples

The ETCH client libraries are published on the ETCH package registry, not on PyPI or npm, so
installing them needs a package token from an ETCH account.
[Before you start](README.md#before-you-start) in the README says where to find it, and each
language's `INSTALL.md` shows where to put it.
